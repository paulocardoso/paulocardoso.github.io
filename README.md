# Paulo Cardoso

Personal landing page for Paulo Cardoso — CTO | Problem Solving.

Published with GitHub Pages from the root of the master branch at https://paulocardoso.co/.

## Files

- index.html — homepage and profile content
- style.css — responsive charcoal theme
- app.js — mobile navigation
- assets/ — unbranded artwork and personal favicon
- CNAME — custom domain
- .nojekyll — publish the static files directly

No build step or package installation is required. To preview locally, run:

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Then open http://127.0.0.1:4173/.
